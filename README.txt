FinWise PWA - cara pasang

1. Buat repo baru di GitHub, mis. "finwise".
2. Upload SEMUA isi folder ini (index.html, manifest.webmanifest, sw.js, folder icons).
3. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. Buka https://USERNAME.github.io/finwise/ di Chrome HP.
5. Menu titik tiga > "Instal aplikasi" / "Tambahkan ke layar utama".
   (iPhone: Safari > Bagikan > Tambah ke Layar Utama.)

Harus lewat HTTPS (GitHub Pages sudah HTTPS) agar bisa dipasang dan berjalan offline.
