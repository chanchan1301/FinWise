# FinWise (PWA)
1. Buat repo GitHub baru, upload semua file ini.
2. Settings > Pages > Deploy from branch > `main` / root.
3. Actions > "Update harga emas" > Run workflow (sekali, lalu otomatis tiap hari).
4. Buka `https://USERNAME.github.io/NAMA-REPO/` di HP > menu browser > "Tambahkan ke layar utama / Instal".
